## 2. 数据流

```text
板端录音（16kHz/16bit/单声道）→ TF 卡 /memoNNNN.wav
        │（拔卡或用读卡器拷到电脑）
        ▼
tools/todo_pipeline/todo_pipeline.py
        ├─ 转写：whisper（本地）/ openai（云端）/ mock（离线演示）
        ├─ 抽取：rules（触发词，离线）/ llm（大模型）/ mock
        ▼
out/todos.md（可勾选待办） + out/transcript.json（原文与时长）
```

## 3. 实现要点

| 点 | 说明 |
|---|---|
| 格式校验 | 复用与 `tf_library.c` 一致的判定：RIFF/WAVE、`fmt` 长度 16、PCM、单声道、16 kHz、16 bit、存在 `data` 块；不合规文件跳过并提示 |
| 时长 | `data 字节数 ÷ (16000×2)`，与板端 `data_bytes / 32` 同源 |
| 离线可用 | `--transcriber mock --extractor rules` 完全不联网；规则抽取用触发词（要/需要/记得/明天/提醒/TODO/need to…）+ 句子切分 + 去重 |
| 可选增强 | `faster-whisper` 本地转写、OpenAI 云端转写、`--extractor llm` 交给大模型整理；缺库时给出可执行的安装提示，不静默失败 |
| 本地转写参数 | 默认 `WHISPER_DEVICE=cpu`、`WHISPER_COMPUTE=int8`（避免无 CUDA 机器加载 cuBLAS 失败）；模型用 `WHISPER_MODEL` 选 `tiny/base/small/medium`；`WHISPER_LANG` 默认 `zh`；`WHISPER_PROMPT` 默认提示“以下是普通话录音，请用简体中文输出”，实测可让输出稳定为简体；国内网络可设 `HF_ENDPOINT=https://hf-mirror.com` |
| 可追溯 | 每条待办附 `<!-- 文件名 · 时间 · 时长 -->`，能回到原始录音 |

## 5. 边界与已知限制

1. **不实时**：先录完落卡，再在电脑上批量处理；不做板端实时转写（无 WiFi、NPU 模型缺失）。
2. **转写质量取决于模型**：`rules` 抽取是启发式，长句/口语化内容建议用 `--extractor llm`。
3. **WAV 可以直接蓝牙拉取**：`tools/ble_memo_sync/sync.py --pull` 已在真机跑通（12 条/975 KB），不必再拔卡。
4. **真实语音转写已在本机验证（tiny 模型）**：`faster-whisper` 1.2.1、CPU int8；tiny 中文准确率有限，建议 `WHISPER_MODEL=small` 或云端。
5. 本工具不修改固件、不改变任何既有行为，回滚只需删除 `tools/todo_pipeline/`。
