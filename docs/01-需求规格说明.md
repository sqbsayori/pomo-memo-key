## 1. 引言

### 1.1 目的与范围

本文描述「闪念胶囊」本期要做和明确不做的事。它是放在桌上的番茄钟，也是不用看屏幕就能按一下录音的便签。

本期做：直立开始倒计时（支持番茄钟与普通倒计时双模式，1–120 分钟以 1 分钟步进可调，支持长按阶梯加速调节，运行中调预设按差值联动剩余时间，提示音可开关）；离开暂停，扣下暂停且静音；KEY2 或平放页面触摸手动开始/停止录音，移除 VAD，完整保留 16 kHz 16-bit 单声道 raw PCM（含所有静音）并写成 WAV；缓冲区写满报告 `CAPSULE_MEMO_NOSPACE`，全静音非空正常保存，零样本为空；TF 卡可用时自动存入独立编号 WAV 文件，支持文件切换、播放和双击确认删除，无卡或挂载/写入失败回退 RAM 并提示未持久化（TF 卡需自备）；侧放发宏（音量加、下一首、系统音频静音，不发麦克风静音）并发送 BLE Consumer Control HID 事件，本地功能独立于蓝牙连接；基于 LVGL 的 3×3 页面网格（390×450），计时居中、左右遥控、平放录音，姿态驱动缓动转场，转场中换姿态平滑重定向，扣下隐藏显示，启用 FT6146 触控配置，保持现有 I2C1 IMU 引脚配置不变。

本期不做：蓝牙传文件（REQ-203）、转写和大模型待办（REQ-204）、神经网络 VAD（REQ-205，已移除 VAD 直接保留完整 PCM）、外壳（REQ-206）。这些保留编号。

### 1.2 术语与缩写

| 术语 | 含义 |
|---|---|
| 直立 / 扣下 / 平放 / 左侧 / 右侧 | 五个要标定的静止姿态 |
| 未知 | 合加速度不像静止重力，或和两个参照都太接近 |
| 桌上 | 出现过直立、平放或扣下之后的一段状态。稳定未知满 3 秒后取消 |
| 宏事件 | 音量加、下一首、系统音频静音。只有类型和递增序号 |

## 2. 产品概述

### 2.1 一句话定位

给自己用的桌面番茄钟。立起来开始计时，扣下去就安静；想记一句时按一下，不用先开屏幕。

### 2.2 目标用户与使用场景

- 目标用户：做这个作业的人自己。
- 典型场景 1：桌上 USB 供电。把板子立住，开始倒计时（番茄钟或普通倒计时，1–120 分钟以 1 分钟步进可调，支持长按阶梯加速调节，提示音可开关）。离开直立暂停，扣下时暂停且静音。
- 典型场景 2：侧放在桌上当宏键盘。左侧短按音量加，右侧短按下一首，任一侧长按系统音频静音；发送 BLE HID Consumer Control 事件。侧放屏幕同时提供对应触控按键。
- 典型场景 3：平放页面触摸或按 KEY2 录音。松手不算结束，再按一次停止。完整保留原始 PCM（包含所有静音）。TF 卡可用时自动落盘并支持切条目、播放和双击确认删除，无卡回退 RAM。口袋场景需自备电池，TF 卡需自备。

### 2.3 核心痛点与现有方案

| 现有方案 | 优点 | 不足 | 本产品的差异点 |
|---|---|---|---|
| 手机番茄钟 | 现成 | 要看屏幕、解锁 | 立起即开始，扣下即暂停 |
| 手机备忘录 | 能转文字 | 要先点开应用 | 一个键开始录音，停录后保留完整原始音频 |
| 小智语音助手 | 板上已经有录音和蓝牙 | 整条链路是对话助手，不是番茄钟 | 本期只取板级事实，不把小智产品搬进来 |

## 5. 硬件约束与接口核对

- [x] 屏幕：1.85 寸 AMOLED 390×450 触摸。已接入 LVGL 3×3 页面网格与 FT6146 触控配置，保持现有 I2C1 IMU 引脚配置不变；触控与 IMU 并发稳定性待实测。
- [x] 传感器：六轴 LSM6DS3TR-C，地址 0x6A。姿态只用加速度。地磁和环境光本期不用。
- [x] 音频：板载 MEMS 麦克风 16 kHz 16-bit 单声道。扬声器只接丝印 SPK，支持结束提示音和 TF 卡 WAV 回放。
- [x] 无线：蓝牙 5.3 在板上，已接入 BLE Consumer Control HID（POMO_MEMO_HID），本地功能独立。无 WiFi。
- [x] 交互：KEY1 为 PA34，不用作录音键。KEY2 为 PA43，消抖，短按/长按触发功能。屏幕触控提供辅助交互按钮。
- [x] 存储：TF 卡槽在，卡需自备。已接入 SPI1 FatFs 录音库与 RAM 回退机制。
- 需要额外采购/焊接的部件：口袋使用要自备电池。TF 卡需自备。振动马达不在本期。

## 6. 我们考虑过但没有选择的方向

| 备选方向 | 没有选择的原因 | 谁做的判断 |
|---|---|---|
| 按某一根轴是否朝上判断姿态 | 外壳有倾角，不知道哪根轴垂直于屏幕 | agent 建议，写入设计 |
| 用片内神经网络做 VAD | 公开资料没有能直接用的模型、输入格式和时延 | agent 建议，写入设计 |
| 能量门限 VAD 静音裁剪 | 环境底噪变化导致门限不稳定，且桌面便签无需切除静音 | 移除 VAD，完整保留 raw PCM |
| 把小智整包当作产品 | 它是对话助手。201MB 的包不进库，只核对板级事实 | 学生确认不入库 |
| 用 KEY1 录音 | 它和电源、长按复位复用 | 维持课程示例的 KEY2 |
