# 闪念胶囊 UI 设计需求简报

> 版本说明（2026-11-12）：本简报是 2026-11 初版设计需求，现固件已经演进，差异以 `README.md` / `docs/02-方案设计说明.md` 为准：
> 直立页改为 **POMO / TIME / STOPWATCH** 三页（无独立 `COUNT` 页），新增顶部药丸切换栏与左右滑动（>40 px）；
> 计时页提供 `↺` 重置与 `▶/⏸` 启停；录音中任意页面左上角新增常驻呼吸红点；未连接时媒体键已置灰。

## 1. 产品定位
闪念胶囊（Pomo Memo Key）是一款桌面多功能硬件，通过翻转机身姿态切换番茄钟计时、多媒体遥控和语音便签功能。

## 2. 屏幕与显示规格
- **屏幕硬件**：1.85 英寸 AMOLED 电容触摸屏。
- **物理面板分辨率**：390 × 450。
- **软件设计画布**：450 × 390（横向视口，画面方向固定，UI 设计与资源切图统一以此为基准）。
- **字体说明**：当前固件内置开源 Montserrat 纯英文字体（可用字号 16、20、24、28、36 px）。新设计若使用中文，需规划中文字体层级并预留合适的排版行高与字宽。
- **触控尺寸与安全区建议**：
  - 画布四周建议预留 >= 16 px 的安全边距，防止内容贴近屏幕物理边缘。
  - 触控按钮尺寸建议 >= 44 × 44 px（推荐 48 × 48 px），相邻按键间隙建议 >= 8 px。

## 3. 页面总览与姿态切换
系统包含 4 个核心功能页面，全部由设备摆放姿态驱动切换，无屏幕滑动手势，无顶部或底部导航栏。

- **直立姿态（STAND）**：进入计时主页。
- **左侧放姿态（SIDE_LEFT）**：进入媒体控制页（左侧位）。
- **右侧放姿态（SIDE_RIGHT）**：进入媒体控制页（右侧位）。功能与界面与左侧位完全相同，方便用户就手操作。
- **放平姿态（FLAT）**：进入语音便签页。
- **扣下姿态（FACE_DOWN）**：屏幕朝下扣在桌上时，屏幕自动熄灭，计时暂停。
- **未知姿态（UNKNOWN）**：机身晃动或倾斜未稳定时，保持当前页面，计时暂停；从扣下进入未知姿态时持续黑屏，直到出现稳定已知姿态。

### 3.1 切换动效与判定规则
- **姿态稳定判定**：新姿态连续稳定保持约 400 ms 后触发切页。
- **转场滑动动效**：页面以平滑滑动动画切入视口，动画时长 260 ms，采用减速缓动（ease-out）。
- **打断连续跟随**：在转场位移途中若检测到新的有效姿态，直接从当前过渡位置平滑滑向最新目标页面。

## 4. 页面详细功能与设计要求

### 4.1 计时主页（直立姿态）
- **页面目的**：用于专注番茄钟或日常倒计时。
- **展示信息**：
  - 当前模式标题：番茄钟（Pomodoro）或普通倒计时（Countdown）及预设分钟。
  - 时间大字：剩余时间倒计时，预设范围为 1 至 120 分钟（文本显示格式支持至 `120:00`，需容纳 3 位数分钟排版，避免文字溢出）。
  - 提示音状态：倒计时结束提示音开关状态（开 / 关）。
- **操作控件**：
  - 模式切换：`POMO`（切至番茄钟）与 `COUNT`（切至倒计时），默认均为 25 分钟，两模式各自独立记忆预设。
  - 时长调节：`-` 与 `+` 按键。短按步进 1 分钟，长按阶梯加速连续增减。
  - 提示音开关：`BEEP` 按键，切换到期蜂鸣开/关。
- **关键状态与交互**：
  - 机身立起自动开始或继续倒计时，离开直立或进入未知姿态自动暂停。
  - 倒计时归零后停留在 `00:00`，离开直立再次立起后恢复预设时长。
  - 界面无手动开始/暂停/重置触控按钮，无工作与休息交替循环。

### 4.2 媒体控制页（左侧放 / 右侧放）
- **页面目的**：充当桌面蓝牙多媒体控制器，控制电脑或手机音频播放。左右侧放界面完全相同。
- **展示信息**：
  - 页面标题：固定展示媒体控制标题。
  - 蓝牙连接状态：展示已连接或未连接配对提示。
- **操作控件**（6 个控制按钮）：
  - 音量调节：音量加（VOL+）、音量减（VOL-）、系统静音（MUTE）。
  - 播放控制：上一首（PREV）、播放/暂停（PLAY/PAUSE）、下一首（NEXT）。
 - **关键状态**：
  - 已连接：显示已连接状态。
  - 未连接：显示配对提示；当前实现不会自动将按钮置灰，重设计可补充禁用态反馈。

### 4.3 语音便签页（放平姿态）
- **页面目的**：桌面快速录制语音备忘并支持本地试听。
- **展示信息**：
  - 录音状态：录音就绪、录制中计时、最近录音时长与保存位置。
  - 文件信息：当前选中的录音文件名或状态提示。
  - 回放状态与进度：回放状态文本与水平回放进度条（0%–100%）。
- **操作控件**：
  - 录音按钮：`RECORD` / `STOP`，未录音显示录音，录音中显示停止。
  - 文件切换：`FILE`，按文件名顺序循环切换卡内选中的录音文件。
  - 播放按钮：`PLAY`，触发音频回放。
  - 删除按钮：`DELETE`，二次确认删除当前选中的录音文件。
- **存储与回放规则**：
  - 单次录音时长上限约 30 秒。
  - 可选 TF 卡保存多条录音，无卡时保留最近一条 RAM 录音。
  - 存在最新有效 RAM 录音时，点击 `PLAY` 优先播放该条录音。
- **关键状态与交互**：
  - 录音进行中：显示录音进行状态与当前时长，录音按钮切换为停止态。
  - 音频回放中：进度条平滑推进，回放状态显示百分比；回放过程不支持拖动进度条、快进或暂停。
  - 删除二次确认：点击 `DELETE` 后按键原位变为确认提示（如 `CONFIRM?`），再次点击执行删除。切换文件、开始新录音或切换到其他已知姿态时取消确认。
  - 异常提示：无存储卡提示、麦克风异常、回放失败、录音超限截断提示。

## 5. 实体按键交互（KEY2）
机身配备一颗物理功能键 KEY2，支持全局操作与姿态感知：
- **全局录音打断**：系统处于录音状态时，在任何姿态下按下 KEY2 均立即停止录音。
- **侧放多媒体宏**：设备在桌面上处于侧放姿态时：
  - 短按（< 600 ms）：左侧放触发音量加（VOL+），右侧放触发下一曲（NEXT）。
  - 长按（>= 600 ms）：左侧或右侧放均触发系统静音（MUTE）。
 - **非侧放录音控制**：在直立或平放等非侧放宏状态下，按下 KEY2 开始录音，再次按下停止录音；松手不会自动停止。
 - **后台录音反馈**：录音进行中改变设备姿态或扣下熄屏不会中断录音。建议在各页面设计常驻录音指示（如顶角红点），提示后台正在录音。

## 6. 动效与视觉要求
- **页面转场**：随姿态切换整体平移滑入，260 ms 减速缓动，视口位移方向与页面相对位置一致。
- **按钮触控反馈**：交互控件包含常规、按下高亮、禁用置灰状态。
- **录音状态反馈**：录音中配合动态呼吸指示或高亮图标，时长数字实时递增。
- **播放进度**：进度条平滑推进，播放结束显示完成状态。
- **二次删除反馈**：删除按钮原位变换文案与警示色，形成明确的防误触反馈。
- **错误与异常提示**：异常文案在状态标签区清晰展示，不使用阻断式弹窗。
- **风格与色彩自由度**：不限定具体配色方案，极简、现代或工业仪表风格均可；需确保在 16-bit AMOLED 屏幕上具备清晰的对比度与可读性。

## 7. 功能边界（明确无需设计项）
- **无多媒体元数据**：不支持获取歌曲封面、歌词、播放列表或音量回传。
- **无网络与云服务**：无 Wi-Fi 配网、云端同步、天气或日历卡片。
- **无语音转写与 AI**：无语音转文字（STT）、智能助手或大模型对话。
- **无多级系统设置**：无设置菜单树、无账号登录、无全屏文件管理器、无系统配对弹窗。
- **无移动端状态栏与手势**：无电池电量栏（设备为桌面常供电）、无信号栏、无下拉通知栏与上滑返回手势。

## 8. 设计交付清单
1. **页面与状态画板**：
   - 4 个核心页面（计时主页、左侧媒体控制、右侧媒体控制、语音便签页）。
   - 关键状态：待机就绪、运行中、禁用置灰、二次确认、异常报错。
2. **尺寸标注图**：
   - 450 × 390 画布下的控件尺寸、坐标锚点、按键间距与边缘留白。
3. **视觉设计资产**：
   - 色彩规范：HEX 色值清单（背景色、卡片面色、文字主/次色、强调色、警示色）。
   - 字体规范：字号、字重与排版行高层级。
   - 图标切图：媒体控制与录音操作图标的透明背景矢量 SVG 及 @1x PNG 切图。
4. **转场与动效说明**：
   - 页面滑动进入/移出方向、时长与缓动规范，按键按压与状态变换动效说明。
