### 4.1 2026-11-08 TF 卡识别与 RAM 录音删除修复（跟进）

- 问题事实：用户报告插入 TF 卡重启后仍未检测到（提示无卡），且 RAM 录音无法删除。
- 根因分析：
  1. **RAM 无法删除**：`src/main.c` 中 `UI_CMD_TF_DELETE` 原逻辑硬编码要求 TF 卡就绪，非 TF 源直接报错拒绝，导致 RAM 模式下点击删除按钮无响应。
  2. **TF 卡未检测到**：用户插入的为 256GB exFAT 格式 TF 卡；底层硬件 SPI 与 MSD 驱动已正常识别 `sd0`（容量 232.96 Gbyte），但因 `project/proj.conf` 未启用 `CONFIG_RT_DFS_ELM_USE_EXFAT=y`，导致 FatFs 在 `f_mount` 时返回 13（`FR_NO_FILESYSTEM`）并回退为 RAM 模式。
- 修复内容：
  1. `src/main.c`：在 `UI_CMD_TF_DELETE` 分支增加 RAM 录音清除逻辑，调用 `capsule_memo_clear` 清空 WAV 长度及录音状态，同步重置 UI 时长（`recording_duration_ms = 0`）与有效标志（`ram_memo_valid = false`）；严格保留 `CONFIRM?` 两次点击确认机制、录音及播放期间禁止删除保护、以及切换文件/录音/播放自动取消确认。
  2. `project/proj.conf`：新增 `CONFIG_RT_DFS_ELM_USE_EXFAT=y`，使能 FatFs 对 exFAT 大容量文件系统的原生支持。
